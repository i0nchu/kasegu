# Research hypothesis — mgrid-regime

登記時間 2026-11-06（UTC），在讀取任何價格資料前寫成。

## 交易命題（可被否定）

- **主假設**：馬丁格爾網格（越跌越加碼、反彈到均價上方一格就全部獲利了結）本質上是「賣出波動 / 賭均值回歸」。它在震盪行情賺小錢、在單邊趨勢中累積部位直到停損或強平。如果存在一個**只用決策時點以前資料**的因子，能預測未來 3 天是震盪還是趨勢，那麼「只在因子判定為震盪時開網格」應比「每天都開網格」有更高的扣成本後期望值，而且期望值為正。
- **市場**：Binance USDⓈ-M 永續合約。標的為每日 point-in-time 前 40 大成交額幣（上市 ≥ 60 天、前一日收盤決定，含之後下市的幣），**排除 BTCUSDT、ETHUSDT**（最低下單金額 100 / 20 USDT，100 USD 本金無法拆成 6 層網格）與非加密標的（股票、ETF、黃金白銀代幣、指數，如 TSLAUSDT、QQQUSDT、XAUUSDT、PAXGUSDT、DEFIUSDT 等，名單在程式中寫死）。
- **決策時間**：每天 00:00 UTC。所有特徵只用 00:00 以前已收盤的 5m K 線（重採樣為 1h / 4h / 1d，皆為已收盤 bar）。
- **預測期間**：3 天（72 小時）。

### 描述性現象 / 預測因子 / 交易策略 / 資金組合（分開）

1. 現象：加密幣價格在 1h–3d 尺度上的趨勢性（efficiency ratio）是否有持續性。
2. 預測因子：下列 8 種 × 2 個回看長度 L ∈ {3 天, 14 天} = 16 個變體，全部在 S2 一起檢定。
   - F1 `ER`：Kaufman efficiency ratio，1h 收盤，|c_t − c_{t−L}| / Σ|Δc|（低 = 震盪）
   - F2 `VR`：variance ratio，Var(24h 重疊報酬) / (24·Var(1h 報酬))（低 = 均值回歸）
   - F3 `ADX`：Wilder ADX(14)，L=3 用 4h bar、L=14 用 1d bar（低 = 無趨勢）
   - F4 `CHOP`：Choppiness index，1h，log10(ΣTR / (maxH − minL)) / log10(n)（高 = 震盪）
   - F5 `AC1`：1h 報酬 lag-1 自相關（負 = 均值回歸）
   - F6 `VOLR`：RV(最近 1 天) / RV(L)（高 = 波動擴張，趨勢風險）
   - F7 `BTCER`：BTC 自身的 ER_L（市場層級，所有幣同值）
   - F8 `RV`：1h 報酬的已實現波動（「只看波動」的基準）
3. 交易策略：見下方「網格規格」。
4. 資金組合：100 USD，最多同時 3 個幣（K=3）。

### 網格規格（S3 候選空間，事前固定）

- 每格間距 `step = k · σ_d`，σ_d = 過去 7 天 1h log 報酬標準差 × √24，夾在 [0.5%, 10%]。
- 共 6 筆訂單：第 0 筆市價（taker）開倉，第 1..5 筆為限價（maker），價格在 P0·(1 ∓ i·step)。數量倍數 m = 1.5（第 i 筆名目 = q0·1.5^i，總和 = 20.78·q0）。
- 止盈：價格回到 均價 ± 1 step（多單在上、空單在下）→ 限價全平（maker）。
- 停損：最後一層再往不利方向 1 step → 市價全平（taker，加停損滑價）；若開盤跳空越過則以開盤價成交。
- 時間出場：72 小時未結束則市價全平。
- 方向 D ∈ {long, short, neutral}（neutral = 同一幣同時開多、空兩個獨立網格，需 hedge mode）。
- k ∈ {0.5, 1.0}。
- 共 6 個網格設定 × 濾網 {無, S2 最佳因子 1, S2 最佳因子 2} = 最多 18 組；**這是 S3 的全部搜尋空間**。濾網門檻 = 因子在 dev 全樣本的有利三分位（例如 ER 最低 1/3）。

### 成本與成交

- maker 0.02%、taker 0.05%；taker 額外滑價：開倉 0.02%、停損/時間出場 0.05%。
- 限價必須「穿價」0.05% 才算成交（low ≤ 價格·(1−0.0005)，賣方對稱），不是碰到就成交。
- 同一根 5m 內的路徑順序採保守假設：本根新成交的層，最早到下一根才可觸發止盈；停損在成交之後檢查。
- Funding：依 Binance 實際結算時點對持有中的名目計算，多付空收（費率為正時）。
- 帳戶：每個幣一個 slot，slot 網格總名目 = 104 USDT（最小單 q0 = 5 USDT），K = 3 時總名目上限 312 USDT ≈ 3.1 倍；neutral 為兩倍。逐倉每 slot 保證金 100/3 USD，若虧損超過保證金視為強平（損失 = 保證金）。
- 選幣：00:00 時可開 slot 數 < 候選數時，依因子最有利者優先；無濾網時依隨機（固定 seed）。

### 基準

- 無濾網（每天都開）、只用 RV（F8）的濾網、隨機子集（同樣數量的隨機日）、以及同期同幣「買進持有 3 天」的價格報酬（衡量方向 beta）。

### 為何扣成本後可能仍有效

- 網格大部分成交是 maker，成本低；加密幣在小時尺度常見假突破與回補（流動性提供者賺取的價差）。若趨勢能被事前避開，左尾可被削減。

### 直接推翻假設的證據

- 沒有任何因子在 dev 對「未來 3 天網格損益」有 Holm 校正後顯著且方向穩定的預測力 → S2 REJECT。
- 有濾網的網格在 dev 扣成本後淨期望值 ≤ 0，或不優於無濾網（配對差異 t < 2）→ S3 REJECT。
- val 上淨期望值 ≤ 0 → VALIDATION_FAILED。

## 預先登記評估

- **S2 主要目標**：T2 = 參考網格（neutral, k=0.5）在該幣該日開始的單一 episode 淨報酬（以 slot 總名目計）；次要 T1 = 未來 72h 的 ER（1h）。
- **S2 統計**：每日橫斷面 Spearman IC，取日平均，t 值用 Newey-West（lag 3，因為 3 天重疊）；16 因子 × 2 目標 = 32 檢定，Holm 校正 5%。並報告池化五分位的平均 T2 與年度（2020H2-21 / 2022 / 2023H1）分組。
- **S2 通過門檻**：至少一個因子對 T2 Holm 顯著，最有利 vs 最不利五分位 T2 差 ≥ 0.3%/episode，三個 dev 子期間符號一致。最多帶 2 個因子進 S3。
- **S3 主要指標**：帳戶層級每日淨報酬（100 USD 起，不複利，以 USD 計）。門檻：dev 平均 > 0 且 NW t > 2；有濾網對無濾網的每日配對差 t > 2；三個子期間中至少兩個為正；成本加倍 + 穿價 0.2% 壓測下仍 > 0；最大回撤 < 40 USD。
- **S4 val（一次）**：凍結候選在 val 上帳戶每日淨報酬平均 > 0，且對無濾網配對差 > 0（單尾 t > 1.65），最大回撤 < 40 USD。過了才考慮 hold；hold 使用需另行記錄。
- **可容忍風險**：最大回撤 40 USD（本金 40%），單筆 slot 最大損失 = 該 slot 保證金 33 USD。
- 若 S2 失敗：仍報告無濾網網格在 dev 的損益作為描述（回答「100 USD 期望收益」），但標記 REJECT，不進 val。
