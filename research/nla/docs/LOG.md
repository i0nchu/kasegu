# NLA（New Listing Alpha，新幣上市效應）研究日誌

研究問題：上市後最初幾小時到幾天的價格、成交量、資金流與市場結構，能否預測接下來 1 小時到 30 天的風險調整後報酬。

流程（照使用者 2026-10-28 的分階段計畫，不跳到參數最佳化）：

| 階段 | 工作 | 產出 |
|---|---|---|
| NLA-01 | 建立完整上市事件資料集 | 各年份上市數、分類、資料品質 |
| NLA-02 | 事件研究 | 上市後 1h～30d 報酬分布（對 BTC、山寨基準） |
| NLA-03 | 單因子檢驗 | 分位數、Spearman IC、跨年一致性 |
| NLA-04 | 多因子及對照組 | 控制市場行情與流動性 |
| NLA-05 | 扣成本交易模擬 | 可交易的策略期望值 |
| NLA-06 | 一次性保留期測試 | 獨立驗證候選 Alpha |

腳本在 `research/nla/`，資料在 `data/research/nla/`（不進 git），結果表在 `research/nla/results/`。

## N1 — NLA-01 上市事件資料集（2026-10-28）

### 資料來源

- 幣安官方封存 data.binance.vision，經 S3 path-style 端點
  `https://s3-ap-northeast-1.amazonaws.com/data.binance.vision` 讀取（雲端容器可直連，
  data.binance.vision 與 api.binance.com 網域本身被擋）。
- 封存保留已下架交易對，因此名冊不依賴現在的 exchangeInfo，沒有存活者偏差。
- 名冊：現貨 3732 個交易對（2017-07～2026-09），USDⓈ-M 合約 1056 個（2020-01～2026-09）。
- 每個事件下載上市後 31 天的 1m K 線（含 taker buy 量），存成 `bars/<event_id>.npz`。
- 基準：BTCUSDT 現貨 1m 全歷史；682 個 USDT 現貨對 1h（含已下架，給 NLA-02 的等權山寨基準用）。

### 事件定義

- 一個事件 = 一個基礎資產在一個市場（現貨或永續）第一次成交。現貨取所有計價幣中最早的那一筆
  （例如 2017-19 年多半先上 BTC / BNB 交易對）。
- `first_trade_time` = 第一根成交量 > 0 的 1m K 線開盤時間（跳過開盤前的零量 K 線）。
- 研究用價格序列（panel）：上市 1 天內出現的 USDT → FDUSD → USDC → BUSD 交易對；沒有的話，
  用最早的 BTC/ETH/BNB 交易對逐分鐘乘上該計價幣的 USDT 價格換算（旗標 `synthetic_usd`）。
- 合約代號去掉倍數前綴（1000PEPE → PEPE，旗標 `multiplier_contract`），現貨的 1000SATS 等同樣處理，
  讓現貨與合約對到同一個資產。
- 某資產在封存中消失 2 個月以上又出現，另立一個事件（`relist`，可能是代號重用）。
- 現貨與合約上市時間分開記錄（`spot_listing_time`、`perp_listing_time`）。

### 分類（只用幣安資料能判斷的部分）

| listing_category | 定義 | 對應使用者的三類事件 |
|---|---|---|
| spot_first | 現貨先上，合約晚 1 天以上或沒有合約 | 首次公開交易 / 他處已交易後上幣安（無法區分） |
| perp_first | 合約先上，現貨晚 1 天以上或沒有現貨 | 同上，但第一個幣安市場是永續 |
| spot_perp_same_day | 現貨和合約在 1 天內都上 | 同上 |
| perp_after_spot | 現貨已交易 1 天以上，後來新增永續 | 第三類「現貨已交易，後來新增永續」 |
| spot_after_perp | 合約已交易 1 天以上，後來才上現貨 | 現貨上市前已有幣安價格 |
| relist | 下架後重新出現 | — |

`prior_market_exists`：perp_after_spot / spot_after_perp / relist 為 `yes_binance`，其他為 `unknown`。
「首次公開交易」與「DEX／其他 CEX 已交易」需要外部資料（CoinGecko 首次報價、DEX 池建立時間），
這一輪沒有做；`announcement_time` 需要幣安公告，也還沒填。Launchpool / 空投 / Alpha 等標籤同樣待補。

### 排除規則（`study_eligible = False`）

槓桿代幣（UP/DOWN/BULL/BEAR）、穩定幣與法幣、2026 年的代幣化美股（NVDAB、TSLAB…，只有 USDT
現貨、沒有合約，共 87 個）、封存起始月就已存在（上市時間被截斷，19 個）、沒有可用的 1m 資料（13 個）。

已下架比例（以該市場最後一個有資料的月份 < 2026-09 計）：2017 72%、2018 75%、2019 44%、
2020 35%、2021 38%、2022 29%、2023 9%、2024 3%、2025 1%。上市 12 個月內就下架的只有 0～12%。

觀察：

1. **幣安的上市方式隨時間完全改變。** 2017-2023 以現貨先上為主；2024 現貨與合約同日上市成為主流；
   2025-2026 幾乎全是合約先上（489 個 perp_first 中 431 個在 2025 之後，416 個從未上現貨）。
   類別和年份高度重疊，所以「類別效應」和「年份／市場行情效應」很難分開，切分開發集與保留期時要處理（見下）。
2. **現貨第一根 K 棒不可交易。** 現貨上市第一分鐘的高低區間中位數 71%，第一筆開盤價相對前 1 小時
   VWAP 的偏離中位數 −27%（10% 分位 −91%，有的高到 +28000%）。永續的第一根就正常得多
   （區間中位數 5.6%，開盤 vs VWAP 中位數 0.1%）。印證「不要拿第一根開盤價當可成交價格」；
   NLA-02 的進場基準會用上市後某個時間點（例如 5 分鐘或 1 小時後）的 VWAP 或收盤價。
3. **2026 年的新合約流動性很低**：首日成交額中位數 360 萬 USDT，2025 年是 2.9 億。成本假設必須分年處理。
4. **perp_after_spot 的延遲很分散**：中位數 600 天，四分位 64～1054 天；很多是 2020-21 年替老幣補上合約。
   研究時可能要再拆「新幣幾週內補上合約」與「老幣補合約」。
5. 時間戳：2025 年起現貨封存改用微秒，已統一成毫秒並檢查 1m 間隔皆為 60000 ms。
