# 指標背離 Alpha 研究紀錄

目標：在加密貨幣永續合約上，用統計方法檢驗「指標背離」（MACD、柱狀圖、RSI、OBV、主動買賣量 CVD、成交量 和價格不同步）是否有扣成本後仍存在的 Alpha，經多輪迭代留下最好的因子，做成完整進出場策略，並做帳戶回測與蒙地卡羅。

## 資料與設定

- 幣池：沿用 `research/fast` 的時點正確幣池。每天取前一天為止 30 天成交額前 40 名、上市滿 60 天的 USDT 永續，包含之後下架的幣，2020-06 到 2026-09 共 385 個幣。訊號只在當天屬於幣池的幣上成立。
- 資料：5 分鐘 K 線（含主動買入量 `tb`）與實際資金費率，重採樣成 15 分、1 小時、4 小時。沒有用 L2 訂單簿，主動買賣量就是 K 線檔裡的 taker buy volume。
- 執行：訊號在 K 棒收盤成立，下一根 5 分鐘 K 棒開盤市價進場。停損以停損價成交，跳空時以開盤價成交；停損和停利在同一根 5 分 K 都碰到時算停損。資金費率照實收付。
- 成本：每邊 0.05% 手續費 + 0.05% 滑點，來回 0.20%；另測每筆再加 0.10% 與 0.20%。
- 樣本：2021-01 到 2023-12 設計（IS），2024-01 到 2026-09 只用來確認（OOS）。所有門檻都只用 IS 決定。
- 統計：同一天很多幣一起出訊號，逐筆 t 值會高估，所以先把每天的交易平均，再對天數算 t 值（下文的 t 都是這個）。

## 背離的定義

樞紐點：第 p 根的高點是 [p-3, p+3] 七根裡最高的，第 p+3 根收盤才確認（不偷看未來）。把它和 5 到 60 根前的上一個樞紐高點 q 配對。

- 一般看跌背離：價格更高的高點（H[p] > H[q]），指標更低（例如 MACD[p] < MACD[q]）。看漲背離是鏡像。
- 隱藏背離：價格沒創新高、指標創新高（趨勢延續型）。
- 對照組：同樣是更高的高點，但指標也跟著創新高（「確認」）。用來回答「背離本身有沒有用，還是只是在局部高點做空就有用」。
- 成交量背離：新高但成交量比上一個高點小。CVD 背離：兩個高點之間的主動淨買量除以這段成交量，越低代表新高沒有主動買盤支撐。

## 結論：DIV-S4 策略（4 小時看跌背離做空）

留下的因子只有兩個，而且都只在做空端成立：

1. **MACD 看跌背離**（核心）：4h 價格創更高的高點，MACD 線（除以價格）沒有跟著創高。
2. **CVD 看跌背離**（加強）：兩個高點之間的主動淨買量相對成交量偏弱，代表新高沒有主動買盤。

淘汰：看漲背離（做多）全部失敗、隱藏背離、成交量背離、OBV 單獨、15m 與 1h 的背離、連續型橫截面背離因子。

### 策略運作原理（Python pseudo code）

```python
# DIV-S4: 4h bearish MACD + CVD divergence, short only
TF = "4h"; K = 3; MIN_SEP, MAX_SEP = 5, 60
MAX_POS = 3; W = 0.10                  # 每筆用權益 10%，最多 3 筆（總曝險 30%）
STOP_ATR, TP_ATR, MAX_HOLD = 1.5, 3.0, 24   # 停損 1.5 ATR、停利 3 ATR（2R）、最多 24 根 4h（4 天）
SCORE_MIN = 0.697                      # IS 決定的門檻（MACD 與 CVD 背離百分位平均的第 80 百分位）

def on_4h_close(sym, bars):            # 每根 4h K 棒收盤呼叫一次
    if sym not in universe_top40_by_30d_volume(yesterday):
        return
    p = bars.index[-1 - K]             # 3 根前的候選樞紐高點
    if bars.high[p] != max(bars.high[p - K : p + K + 1]):
        return                         # 不是樞紐高點
    q = previous_pivot_high(bars, before=p, min_sep=MIN_SEP, max_sep=MAX_SEP)
    if q is None or bars.high[p] <= bars.high[q]:
        return                         # 沒有更高的高點，不是背離型態

    macd = (ema(bars.close, 12) - ema(bars.close, 26)) / bars.close
    macd_div = macd[q] - macd[p]       # > 0：價格新高但 MACD 沒新高
    delta = sum(2 * bars.taker_buy[q + 1 : p + 1] - bars.quote_vol[q + 1 : p + 1])
    cvd_div = -delta / sum(bars.quote_vol[q + 1 : p + 1])   # > 0：新高沒有主動買盤
    score = (pct_rank_is(macd_div, "macd") + pct_rank_is(cvd_div, "cvd")) / 2
    if score < SCORE_MIN:
        return

    if open_positions() >= MAX_POS or has_position(sym):
        return                         # 帳戶層級上限，滿了就放棄這個訊號
    atr = atr14(bars)[-1] / bars.close[-1]
    qty = W * equity() / price(sym)
    entry = market_sell(sym, qty)      # 下一根開盤市價做空
    place_stop(sym, entry * (1 + STOP_ATR * atr))      # 交易所端停損單
    place_take_profit(sym, entry * (1 - TP_ATR * atr))
    schedule_exit(sym, after_bars=MAX_HOLD)            # 4 天到期市價平倉
```

`pct_rank_is` 用設計期（2021~2023）所有 4h 新高樞紐的分布換算百分位，實盤時固定不再更新。只用 MACD 的簡化版：`macd_div >= -0.000714`（同樣是 IS 第 80 百分位，接近「MACD 沒創新高」的經典定義），表現略差（見 D7）。

### 初步預期（MACD + CVD，最多 3 筆）

- 交易頻率：約每月 23 筆，平均持有 1.7 天；勝率約 45%，平均獲利 +8.5%、平均虧損 −5.4%（每筆名目），每筆淨 +0.8%。
- 建議起步規模：每筆權益 10%、最多 3 筆。歷史年化約 24%、最大回撤約 −19%；一年後中位數 1.24 倍，約 10% 機率一年後虧損。以 100 USDT 帳戶來說，每筆名目 10 USDT，一年中位數約 +24 USDT，最差 5% 約 −6 USDT。
- 加大到每筆 20% 年化約 49%，但一年內回撤超過 20% 的機率約六成。

### 風險與限制

- 只做空，報酬有一部分來自 2021~2026 山寨幣長期走弱；2023 年（山寨幣反彈）全年 −14%，對照組 −52%。如果遇到長期山寨季，預期會持續小虧。
- 獲利集中在崩盤日，性質像「崩盤保險」：多數時間小輸小贏，靠少數大跌日拉開。
- t 值約 2.5~4，在 720 組以上的搜尋下屬於中等強度；鄰近參數幾乎都為正是主要的信心來源。
- 市價進場、停損可能被軋空跳空；成本壓力測試每筆再加 0.2% 仍為正，但小幣做空的借券與軋空風險沒有被模擬。
- 下一步建議先用紙上交易跑 1~2 個月，確認實際成交與滑價，再考慮和 EPR15 並行（兩者相關 −0.09）。

合計：DIV-S4 扣一籃子後 IS +109 bp（t 4.6）、OOS +40 bp（t 2.2）；對照組 IS +61（t 3.5）、OOS +9（t 0.7）。

解讀：

- 2022、2025、2026 的原始獲利有一半以上來自「整個山寨幣在跌」，不是挑幣能力。確認期（2024~26）原始 +83 bp 裡，約 +43 bp 是一籃子下跌、+40 bp 是這個幣相對一籃子多跌。
- 扣掉一籃子後，DIV-S4 每一年都是正的，包括 2023（原始 −11、扣後 +34）。對照組扣掉後在 2022 和 2026 是負的。所以「背離比對照組好」這件事在市場中性下仍成立，只是幅度在確認期縮到約 +30 bp。
- 2021 一年就貢獻了很大一部分（扣後 +202 bp），之後每年 +26~+49 bp，有逐年變小的跡象。
- 拿掉獲利最好的 10 天後，原始每筆 +45 bp、扣後 +62 bp，表示扣掉一籃子後的優勢不是靠那幾個崩盤日。

程式：`d9_audit.py`；結果在 `results/D9_audit/`（`checks.json`、`variants.csv`、`exit_reasons.csv`、`yearly.csv`）。

## D10：多輪選模稽核（2026-10-27）

### 確認期（OOS）被用了幾次

D1~D8 每一步的結果表都同時列出設計期和確認期，而且有 5 步的決定直接參考了確認期：

| 步驟 | 結果列數 | 有沒有列出確認期 | 確認期怎麼影響決定 |
|---|---|---|---|
| D1 | 540 | 有 | 切片時用「兩期一致」挑出 1h CVD |
| D2 | 192 | 有 | 因為確認期反轉而淘汰主動買賣量因子 |
| D3 | 720 | 有 | 用「兩期都 t>2」當篩選條件，留下 6 組 |
| D4 | 27 | 有 | 1h CVD 因為確認期和對照組分不開而淘汰，只留 4h MACD |
| D5 | 24 | 有 | 兩期一起看穩健性（沒有改規則） |
| D6 | 96 | 有 | 加入 CVD：設計期三分組 −8 / +31 / +19 bp 不是單調的，確認期 −11 / +46 / +85 才是單調，加入 CVD 主要是看確認期 |
| D7 | 81 | 有 | 三個規則兩期都看過後選 MACD + CVD |

合計約 1,680 列結果都附帶確認期數字。所以 2024-01 ~ 2026-09 實際上是開發資料，不能再叫 OOS。D7 / D8 裡「確認期年化 85%、Sharpe 1.47」這類數字應該看成樣本內結果。

### 只看設計期會選到 DIV-S4 嗎

D3 的 720 組裡，設計期 t>2 的有 19 組，純靠運氣預期約 16 組，也就是設計期本身幾乎看不出訊號。4h MACD 做空在設計期排第 10（t 2.57），前面幾名是只有 3~5 筆的 4h 做多、或每筆為負的 1h CVD。只用設計期不會特別挑中它；它是靠「確認期也 t>2」才被選出來的。這一步本身是合理的一次確認，問題在於之後 D4~D7 又反覆用同一段資料。

### 排列檢定：背離強度是否真的有資訊

做法：所有 4h 樞紐事件的出場結果和時間不動，只把特徵（16 個 D6 特徵一起）在同一個月或同一天內隨機打亂，重算 1,000 次。

- 「單一檢定」：MACD + CVD 最強 20% 比全部做空多賺多少，和打亂後比。
- 「整族檢定」：D6 實際看過 16 個特徵 × 多空 × 最強 / 最弱三分之一（64 種切法）再加上 MACD + CVD，取打亂後最好的一個，看 MACD + CVD 能不能贏過「隨便挑最好的」。

| 打亂範圍 | MACD + CVD 最強 20% 多賺 | 單一檢定 p | 打亂後最好切法的中位數 / 95% | 整族檢定 p | MACD 最強三分之一多賺 | 單一檢定 p |
|---|---|---|---|---|---|---|
| 同一個月內 | +35 bp | < 0.001 | +45 / +56 bp | 0.96 | +24 bp | < 0.001 |
| 同一天內 | +35 bp | 0.11 | +30 / +39 bp | 0.14 | +24 bp | 0.009 |

解讀：

- 月內打亂：背離強度和結果的關係不是月份行情造成的（單一 p < 0.001）。整族 p 很高是因為趨勢、ATR、資金費率這類「行情狀態」特徵在月內打亂後仍保有時間資訊，這個比較對 DIV-S4 不公平，僅供參考。
- 日內打亂只讓特徵決定「同一天做空哪個幣」：MACD 單獨還有 p 0.009，MACD + CVD 的 p 只有 0.11。代表 MACD + CVD 的額外貢獻有一大部分是「哪幾天出現強背離」（擇時），而不是同一天裡挑對幣。
- 把 D6 看過的 64 種切法算進去後，MACD + CVD 的整族 p 是 0.14，沒有達到 5% 顯著。

### 多重檢定修正

DIV-S4 帳本（每筆 10%、最多 3 筆）2021-01 ~ 2026-09：交易日的日 t 值 4.05；帳戶有交易的 1,018 天日 Sharpe 0.099（相當於 t 3.2）。

| 假設實際試過的組數 | Bonferroni 需要的 t | Deflated Sharpe（> 0.95 才算通過） |
|---|---|---|
| 100 | 3.48 | 0.55 |
| 720（D3 網格） | 3.98 | 0.25 |
| 1,600（D1~D7 全部） | 4.16 | 0.16 |

Deflated Sharpe 用 D3 720 組設計期 t 值的變異（標準差 1.20）估計「試很多組時最好那組的運氣」。結果：逐筆 t 值剛好落在多重檢定門檻邊緣；帳戶層級的 Sharpe 在任何合理的試驗數下都沒通過。

### D10 小結

- 確認期被用了至少 5 次，現在只能當開發資料。
- 修正多重比較後，DIV-S4 的證據是「邊緣」：沒有被推翻，但也沒有達到統計上可以排除運氣的程度。
- 最站得住的部分是 MACD 背離本身（日內打亂 p 0.009、扣一籃子後每年為正）；CVD 加強的部分主要靠確認期挑出來，也比較像擇時。

程式：`d10_selection.py`；結果在 `results/D10_selection/`。

## D10 保留期：預先登記（在執行前寫下並提交）

資料最早到 2020-05-01。2020-05-15 ~ 2020-12-31（約 7.5 個月、2021 年前曾進幣池的幣 59 個）從 D1 到 D9 都沒有算過任何 DIV-S4 的數字（D9 產生的這段事件檔沒有被匯總或印出）。先前另一個研究（W 底 / M 頭）曾用過這段期間一次，但那是不同策略，看的是它的勝率和市場狀態；我們只知道一般行情：2020 下半年山寨幣大致上漲（DeFi 夏天、第四季 BTC 大漲），類似 2023，原始做空預期偏弱。

凍結的設定：

- 規則、出場、成本與 D7 / D9 完全相同；MACD 與 CVD 的百分位參考 2021~2023 的分布，門檻 0.6966（MACD 單獨 −0.000714）。
- 帳戶：最多 3 筆、每筆權益 10%、每幣一筆。
- 2020-05-15 前的事件不算（指標暖機）。

判定標準（只跑一次，結果照實記錄，不再改規則）：

1. 主要：DIV-S4 扣一籃子後的每筆平均 > 0。
2. 主要：DIV-S4 原始每筆平均 > 對照組（所有更高高點都做空）原始每筆平均。
3. 次要（只記錄）：DIV-S4 原始每筆 > 0；綜合成交壓力版本；帳戶報酬與最大回撤。

1 和 2 都成立才算「保留期支持」；任一不成立記為「保留期不支持」。預期筆數不多（可能少於 150 筆），通過只能算弱的支持證據，失敗則是重要的反面證據，因為這是最後一段沒用過的歷史資料。這段用完後，下一次驗證只能靠 2026-10 以後的新資料或紙上交易。
