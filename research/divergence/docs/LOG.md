# 指標背離 Alpha 研究紀錄

目標：在加密貨幣永續合約上，用統計方法檢驗「指標背離」（MACD、柱狀圖、RSI、OBV、主動買賣量 CVD、成交量 和價格不同步）是否有扣成本後仍存在的 Alpha，經多輪迭代留下最好的因子，做成完整進出場策略，並做帳戶回測與蒙地卡羅。

## 資料與設定

- 幣池：沿用 `research/fast` 的時點正確幣池。每天取前一天為止 30 天成交額前 40 名、上市滿 60 天的 USDT 永續，包含之後下架的幣，2020-06 到 2026-09 共 385 個幣。訊號只在當天屬於幣池的幣上成立。
- 資料：5 分鐘 K 線（含主動買入量 `tb`）與實際資金費率，重採樣成 15 分、1 小時、4 小時。沒有用 L2 訂單簿，主動買賣量就是 K 線檔裡的 taker buy volume。
- 執行：訊號在 K 棒收盤成立，下一根 5 分鐘 K 棒開盤市價進場。停損以停損價成交，跳空時以開盤價成交；停損和停利在同一根 5 分 K 都碰到時算停損。資金費率照實收付。
- 成本：每邊 0.05% 手續費 + 0.05% 滑點，來回 0.20%；另測每筆再加 0.10% 與 0.20%。
- 樣本：2021-01 到 2023-12 設計（IS），2024-01 到 2026-09 只用來確認（OOS）。所有門檻都只用 IS 決定。
- 統計：同一天很多幣一起出訊號，逐筆 t 值會高估，所以先把每天的交易平均，再對天數算 t 值（下文的 t 都是這個）。

## 背離的定義

樞紐點：第 p 根的高點是 [p-3, p+3] 七根裡最高的，第 p+3 根收盤才確認（不偷看未來）。把它和 5 到 60 根前的上一個樞紐高點 q 配對。

- 一般看跌背離：價格更高的高點（H[p] > H[q]），指標更低（例如 MACD[p] < MACD[q]）。看漲背離是鏡像。
- 隱藏背離：價格沒創新高、指標創新高（趨勢延續型）。
- 對照組：同樣是更高的高點，但指標也跟著創新高（「確認」）。用來回答「背離本身有沒有用，還是只是在局部高點做空就有用」。
- 成交量背離：新高但成交量比上一個高點小。CVD 背離：兩個高點之間的主動淨買量除以這段成交量，越低代表新高沒有主動買盤支撐。

## 結論：DIV-S4 策略（4 小時看跌背離做空）

留下的因子只有兩個，而且都只在做空端成立：

1. **MACD 看跌背離**（核心）：4h 價格創更高的高點，MACD 線（除以價格）沒有跟著創高。
2. **CVD 看跌背離**（加強）：兩個高點之間的主動淨買量相對成交量偏弱，代表新高沒有主動買盤。

淘汰：看漲背離（做多）全部失敗、隱藏背離、成交量背離、OBV 單獨、15m 與 1h 的背離、連續型橫截面背離因子。

### 策略運作原理（Python pseudo code）

```python
# DIV-S4: 4h bearish MACD + CVD divergence, short only
TF = "4h"; K = 3; MIN_SEP, MAX_SEP = 5, 60
MAX_POS = 3; W = 0.10                  # 每筆用權益 10%，最多 3 筆（總曝險 30%）
STOP_ATR, TP_ATR, MAX_HOLD = 1.5, 3.0, 24   # 停損 1.5 ATR、停利 3 ATR（2R）、最多 24 根 4h（4 天）
SCORE_MIN = 0.697                      # IS 決定的門檻（MACD 與 CVD 背離百分位平均的第 80 百分位）

def on_4h_close(sym, bars):            # 每根 4h K 棒收盤呼叫一次
    if sym not in universe_top40_by_30d_volume(yesterday):
        return
    p = bars.index[-1 - K]             # 3 根前的候選樞紐高點
    if bars.high[p] != max(bars.high[p - K : p + K + 1]):
        return                         # 不是樞紐高點
    q = previous_pivot_high(bars, before=p, min_sep=MIN_SEP, max_sep=MAX_SEP)
    if q is None or bars.high[p] <= bars.high[q]:
        return                         # 沒有更高的高點，不是背離型態

    macd = (ema(bars.close, 12) - ema(bars.close, 26)) / bars.close
    macd_div = macd[q] - macd[p]       # > 0：價格新高但 MACD 沒新高
    delta = sum(2 * bars.taker_buy[q + 1 : p + 1] - bars.quote_vol[q + 1 : p + 1])
    cvd_div = -delta / sum(bars.quote_vol[q + 1 : p + 1])   # > 0：新高沒有主動買盤
    score = (pct_rank_is(macd_div, "macd") + pct_rank_is(cvd_div, "cvd")) / 2
    if score < SCORE_MIN:
        return

    if open_positions() >= MAX_POS or has_position(sym):
        return                         # 帳戶層級上限，滿了就放棄這個訊號
    atr = atr14(bars)[-1] / bars.close[-1]
    qty = W * equity() / price(sym)
    entry = market_sell(sym, qty)      # 下一根開盤市價做空
    place_stop(sym, entry * (1 + STOP_ATR * atr))      # 交易所端停損單
    place_take_profit(sym, entry * (1 - TP_ATR * atr))
    schedule_exit(sym, after_bars=MAX_HOLD)            # 4 天到期市價平倉
```

`pct_rank_is` 用設計期（2021~2023）所有 4h 新高樞紐的分布換算百分位，實盤時固定不再更新。只用 MACD 的簡化版：`macd_div >= -0.000714`（同樣是 IS 第 80 百分位，接近「MACD 沒創新高」的經典定義），表現略差（見 D7）。

### 初步預期（MACD + CVD，最多 3 筆）

- 交易頻率：約每月 23 筆，平均持有 1.7 天；勝率約 45%，平均獲利 +8.5%、平均虧損 −5.4%（每筆名目），每筆淨 +0.8%。
- 建議起步規模：每筆權益 10%、最多 3 筆。歷史年化約 24%、最大回撤約 −19%；一年後中位數 1.24 倍，約 10% 機率一年後虧損。以 100 USDT 帳戶來說，每筆名目 10 USDT，一年中位數約 +24 USDT，最差 5% 約 −6 USDT。
- 加大到每筆 20% 年化約 49%，但一年內回撤超過 20% 的機率約六成。

### 風險與限制

- 只做空，報酬有一部分來自 2021~2026 山寨幣長期走弱；2023 年（山寨幣反彈）全年 −14%，對照組 −52%。如果遇到長期山寨季，預期會持續小虧。
- 獲利集中在崩盤日，性質像「崩盤保險」：多數時間小輸小贏，靠少數大跌日拉開。
- t 值約 2.5~4，在 720 組以上的搜尋下屬於中等強度；鄰近參數幾乎都為正是主要的信心來源。
- 市價進場、停損可能被軋空跳空；成本壓力測試每筆再加 0.2% 仍為正，但小幣做空的借券與軋空風險沒有被模擬。
- 下一步建議先用紙上交易跑 1~2 個月，確認實際成交與滑價，再考慮和 EPR15 並行（兩者相關 −0.09）。

# 第二部分：預測背離（雙頂 vs 真突破）

問題（使用者手單做法）：上漲 L0 → 擺盪高點 H1（MACD 波峰 M1）→ 回調 L1（L1 > L0，上漲偏見沒破）→ 第二次上漲、MACD 拐頭向上、價格仍在 H1 之下。這時預測價格會「突破 H1」還是「做雙頂跌破 L1」，並提前做空（等於預測 MACD 會背離，而不是等背離出現）。多方鏡像同樣測。

## 量化定義

- 週期 1h、4h；H1 是 k=3 的樞紐高點；L0 是 H1 前 60 根最低點，L0 → H1 至少 2 ATR。
- 判斷點 t：H1 確認後 60 根內，第一根「MACD 線拐頭向上」（macd[t] > macd[t-1] ≤ macd[t-2]）且價格仍低於 H1、MACD 仍低於 M1、回調至少 1 ATR、L1 > L0 的 K 棒。
- 答案：t 之後 120 根內先碰到哪一邊。先突破 H1 = 真突破；先跌破 L1 = 雙頂。突破時再記錄 MACD 是否低於 M1（事後是否形成背離）。
- 交易：t 的下一根 5 分 K 開盤做空，停損 H1（+0 / 0.5 / 1 ATR），停利 L1，最多 60 根。
- 特徵（t 當下已知）：位置（recov = 從 L1 收復了 H1-L1 的幾成、離 H1 幾個 ATR、回調深度）、第二段 vs 第一段每根成交量、當根量 vs 30 天均量、兩段的主動淨買比例與變化、24 小時資金費率與 H1 以來的變化、ATR 從 H1 到現在的變化、短 / 長波動率比、MACD 距 M1 多遠與拐頭斜率、兩段經過的根數、EMA200 趨勢、RSI。

## 結論

- 在 MACD 背離「發生之前」進場，統計上接近擲硬幣：結果幾乎完全由價格目前在 H1 和 L1 之間的位置決定，這就是隨機漫步的特性。停損放在 H1 之上、目標放在 L1，勝率和賠率會自動互相抵消。
- 量縮、波動收斂、資金費率偏低確實讓雙頂多一點，方向和手單經驗一致，但只多 1~3 個百分點，不夠付 0.2% 的來回成本。
- 高勝率是陷阱：加過濾後勝率 70%，但因為停損在 H1 上方、虧損比獲利大，期望值仍為負。
- 有優勢的是「等背離確認後再做空」（第一部分的 DIV-S4）：突破的情況中有 60% 會形成背離高點，而 4h 背離高點確認後做空每筆 +40~80 bp。也就是說，提前預測的部分沒有優勢，優勢在價格真的創高、但 MACD 和主動買盤跟不上的那一刻。

## E8：使用者修正版（提前預測雙底 / 底背離，策略修正.pdf）

使用者看過 E6 的圖後指出：之前的進場和手單是不同的東西。手單的邏輯是：

- 先看 MACD 判斷趨勢背景。
- 在第一個極值（L0）和反彈高點（頸線 H1）出現之後，價格回頭測試 L0 時進場。
- 不跌破 L0 會走成 W 底；跌破 L0 但 MACD 沒創新低，就是底背離。兩種都能獲利，只有跌破後繼續下跌（延續）會止損。
- 最佳買點在 H1-L0 中點到 L0 之間。
- 型態必須是同級別的波段，MACD 也不能已經明顯穿越零軸、變成更大週期的調整。
- 做空是鏡像（雙頂 / 頂背離）。

量化方式（做多為主，做空把價格取負後套同一套程式）：

```python
# 在 1h / 4h K 線上，H1（頸線）確認為樞紐高點（左右 K 根）時檢查
L0 = lowest_low(bars[H1 - 60 : H1])          # 第一底，必須是樞紐低點，H1 是 L0 以來最高
H0 = highest_high(bars[L0 - 60 : L0])        # 下跌段起點
M0 = min(macd near L0)                       # L0 附近 MACD 低點
context = (M0 < 0                            # MACD 在零軸下：下跌趨勢
           and macd crossed from >= 0 to < 0 during H0 -> L0
           and 0.382 <= (H1 - L0) / (H0 - L0) < 1      # 反彈是同級別，但不是新趨勢
           and 0.2 <= bars(L0 -> H1) / bars(H0 -> L0) <= 5
           and max(macd from L0 to now) <= 0.25 * abs(M0)   # MACD 修復到零軸附近、沒有翻多
           and (H0 - L0) >= 3 * ATR)
if context and price still above L0:
    place buy limit at L0 + x * (H1 - L0)    # x = 0.5 / 0.25 / 0 / -0.15（中點 ~ 跌破 L0 一點）
    wait up to bars(L0 -> H1) bars; cancel if price breaks above H1 first
on fill:
    stop = L0 - 0.5 * (H1 - L0)              # 或 0.25
    if a bar closes below L0 and macd < M0:  # 跌破 L0 卻沒有背離 = 延續，下一根開盤出場
        exit
    take profit at H1（全部），或 H1 平一半 + 保本 + 看等幅 H1 + (H1 - L0)
    time exit after 60 bars
```

時間對稱的下限放寬到 0.2，因為使用者標註的 BCH 範例（2025-12-15 的 L0）是 8 天下跌後 2 天反彈（0.23）。程式在這個範例抓到的買點和使用者標的一樣：2025-12-18 06:40 在 530.8 做多，同日 13:55 在頸線 568.2 止盈，+6.9%。

結構止損的距離差異很大（中位數 4h 約 10~15%，1h 約 5~7%），所以改用 R 倍數（每筆風險 = 進場到停損的距離）比較，帳戶模擬也是每筆固定虧 1% 權益。

### 結果（K=3，停損 L0 − 0.5 × (H1 − L0)，啟用「無背離出場」，頸線全部止盈）

| 組合 | 期間 | W 底 | 背離 | 延續（止損） | 頸線命中率 | 擲硬幣 | 每筆 R |
|---|---|---|---|---|---|---|---|
| 4h 做空 x=0.5 規則 | IS / OOS | 40% / 45% | 11% / 12% | 37% / 33% | 51% / 57% | 65% | −0.07 / −0.01 |
| 4h 做空 x=0.25 規則 | IS / OOS | 18% / 22% | 18% / 19% | 52% / 51% | 37% / 41% | 50% | −0.08 / −0.05 |
| 4h 做多 x=0.5 規則 | IS / OOS | 44% / 46% | 8% / 8% | 30% / 36% | 52% / 53% | 65% | −0.02 / −0.06 |

| 1h 做空 x=0.5 規則 | IS / OOS | 46% / 48% | 12% / 12% | 34% / 33% | 57% / 59% | 65% | −0.03 / 0.00 |
| 1h 做空 x=0.5 不篩選 | IS / OOS | 40% / 40% | 8% / 8% | 33% / 33% | 48% / 48% | 65% | −0.03 / −0.02 |

- 使用者的背景條件確實有資訊：和不篩選相比，頸線命中率在兩期、多空、1h/4h 都穩定高 5~10 個百分點，跌破 L0 後走成背離的比例也較高。
- 但所有組合仍低於擲硬幣的命中率，扣成本後每筆約 0R 或為負。原因是一部分單在時間到期或「無背離出場」時離場，沒有走到頸線或止損。
- 入場位置是用勝率換盈虧比：x=0.5 勝率約 55~63%（盈虧比 0.5）；x=0.25 約 45~50%（盈虧比 1）；x=0 約 25~35%（盈虧比 2）；x=−0.15 約 25~30%（盈虧比 3.3）。每一檔的勝率都剛好落在盈虧平衡附近。
- 分批止盈（頸線平一半 + 保本 + 等幅）比全部止盈略好，約 0~0.03R。
- 樞紐 K=5（更明顯的波峰波谷）結果相近。

帳戶層級（最多 3 筆、每幣一筆、每筆風險 1%，分批止盈，年化 IS / OOS）：

- 4h 做空 x=0.5 規則：K=3 −7% / +4%，K=5 −9% / +8%。
- 1h 做空 x=0.5 不篩選：K=5 +0% / +21%，K=3 −4% / −8%。
- 做多全部為負。2024~26 做空較好，和之前 4h 做空的發現一樣偏向空頭時期，兩期不一致。

結論：把手單規則寫成程式之後，使用者標的範例抓得到，背景條件也有用（命中率比不篩選高 5~10pp）。但結果還不夠扣成本，只能列為觀察。可能還缺：

- 手單「放棄不做」的判斷（例如 AVAX 那種不同級別的擺動），目前只用比例篩選。
- 更聰明的止損。很多止損單是被 L0 下方的影線掃掉後才反轉，例如代表性圖中的 LTC 2025-01-13。
