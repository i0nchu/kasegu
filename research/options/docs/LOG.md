# 虛值短天期期權搏高倍 研究紀錄

2026-11-06。目標：小資金快速滾倉，不要求正期望值。問題：買 2-3 天到期的虛值（OTM）期權，打到 2x / 5x / 10x 的機率，跟 BTC 10x 合約（bold-play）比誰好。

## O1 資料

- 雲端容器連不到交易所，改用 GitHub Actions（`.github/workflows/options-fetch.yml`，跑 `code/fetch.py`）抓資料並 commit 到 `data/`。
- Deribit：2021-04-01 ~ 2026-11-05 每天 08:00-09:00 UTC（剛交割完）所有 BTC/ETH 期權成交，聚合成每個合約一列（vwap、首筆 IV、指數價），只留 4.5 天內到期。BTC 104k 列、ETH 92k 列。另有 1h 永續價、1h DVOL。
- 交割價用永續 08:00 開盤價代替（Deribit 交割 = 08:00 前 30 分鐘指數 TWAP，差異很小）。Deribit `get_delivery_prices` 只回 300 筆，不夠用。
- OKX：公開 API 沒有完整的歷史期權成交，只抓了 2026-11-06 17:28 UTC 的即時盤口快照，跟 Deribit 同時間比較。

## O2 成本假設

- 進場價 = 該小時 vwap + 1 tick（0.0001 BTC，接近買在賣一價）。另測 0 / 2 tick。
- Taker 手續費 min(0.03% 標的, 12.5% 權利金)；交割費 min(0.015%, 12.5% 價值)。
- 每天每個（方向, 到期天數, OTM 檔位）挑成交量最大的一個合約。OTM 檔位：0-2%、2-4%、4-6%、6-9%、9-13%。
- 以美元計：成本 = (價格+費用)×進場指數；價值 = 到期內含價值 − 交割費。

- Call 3d 4-6% 平均 1.85 是少數極端日（大漲）撐起來的，不可信。

## O4 全押滾倉（每次到期再全押下一張，100 USD 起）

輸一次就歸零，所以 30 天和 90 天結果幾乎一樣。

| 規則 | BTC 2x | 5x | 10x | ETH 2x | 5x | 10x |
|---|---|---|---|---|---|---|
| Call 3d 0-2% 持有到期 | 20% | 10% | 5.6% | 24% | 11% | 5.9% |
| Call 3d 0-2% 漲到 2x 就賣 | 36% | 10% | 4.1% | 41% | 11% | 4.7% |
| Call 3d 2-4% 漲到 3x 就賣 | 25% | 8% | 6.4% | 26% | 10% | 6.3% |
| Call 3d 2-4% 漲到 2x 就賣 | 34% | 11% | 5.3% | 39% | 13% | 6.2% |
| Put 3d 0-2% 漲到 2x 就賣 | 37% | 10% | 5.4% | 37% | 10% | 5.6% |

- 提前止盈用 Black-Scholes 以進場 IV 每小時重估，扣 1 tick + 手續費；IV 固定不變是簡化。
- 分段穩定：BTC Call 3d 0-2% 止盈 2x 在 2021-23 = 32%、2024-26 = 38%。
- 達標很快：中位數 3 天到 2x、6-9 天到 10x（有達到的那些）。
- 小比例下注（每次 10% 資金）跑一年：10x 機率在 0%~34% 間亂跳，完全看有沒有碰到大行情，不採用。

## O5 OKX vs Deribit 盤口（2026-11-06 17:28 UTC，BTC 約 76,000）

| | OKX | Deribit |
|---|---|---|
| 最小單位 | 1 張 = 0.01 BTC | 0.1 BTC |
| 價格 tick | 0.0001 BTC | 0.0001 BTC（>0.005 時 0.0005） |
| 價平附近 2 天期價差 | 1 tick，2-9% | 2-4 tick，9-20% |
| 4% 以上虛值（權利金 1-3 tick） | 40-100% | 40-100% |
| 賣一深度 | 幾 BTC 以上 | 幾 BTC 以上 |

- OKX 價平附近確實比較緊，用 OKX 成本大約接近本研究 0 tick 的情境（平均倍數多 4-8%）。
- 100 USD 在兩邊都買得起；深度對 100 USD 沒有影響，真正的成本是 tick 相對權利金太大。
- OKX 手續費：taker 0.03% 標的，上限權利金的 7%~12.5%（依官方頁面不同說法），比 Deribit 略好或相同。

## O6 結論

- 期權全押滾倉：2x 約 35-40%、5x 約 10-13%、10x 約 5-6%。
- BTC 10x 合約（姊妹研究）：2x 約 50%、5x 約 20%、10x 約 10-14%。
- 每一個目標合約都比較好。期權的優勢只有兩個：不會被插針爆倉、達標速度快（3 天一輪）。
- 單張 10x 樂透：最好的是 BTC Call 3d 4-6%，單次 ≥10x 約 3.7%（大約 27 張中一張）。
